## 🚀 Quick Setup & Local Preview

No build step, Node.js, or npm dependencies required!

### Option 1: Direct Browser
Simply double-click `index.html` to open it in Google Chrome, Microsoft Edge, Firefox, or Safari.

### Option 2: Live Server (Python)
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## 🌐 Free Deployment Guide

### Method A: Deploy on GitHub Pages (Recommended)

1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Update portfolio with official resume details"
   ```
2. Link your remote repository:
   ```bash
   git remote add origin https://github.com/Vishal6377Patel/portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. In GitHub repo settings, go to **Pages**, select branch `main` and folder `/ (root)`, then click **Save**.
4. Live site: `https://vishal6377patel.github.io/portfolio/`

### Method B: Deploy on Netlify (1-Click Drag & Drop)
Drag and drop this entire folder into [app.netlify.com/drop](https://app.netlify.com/drop).
